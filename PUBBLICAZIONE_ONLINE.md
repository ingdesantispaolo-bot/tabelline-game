# 🌐 Come Pubblicare "Matemagica" Online Gratuitamente

Ecco i **3 metodi migliori, gratuiti al 100% e a manutenzione zero** per pubblicare il gioco sul web e renderlo giocabile da qualsiasi smartphone, tablet o PC nel mondo con indirizzo HTTPS sicuro:

---

## ⚡ Metodo 1: Vercel (Consigliato per Rapidità & Performance AAA)
Vercel è la piattaforma cloud globale più veloce per siti web e applicazioni statiche:
1. Fai doppio click sul file [`pubblica_su_vercel.bat`](file:///c:/Users/icopa/.gemini/antigravity/scratch/tabelline-game/pubblica_su_vercel.bat).
2. Se è la prima volta, ti chiederà di autenticarti (con email o GitHub).
3. Premi **Invio** a tutte le domande per confermare le impostazioni predefinite.
4. In **30 secondi** otterrai un URL pubblico permanente (es. `https://matemagica-tuonome.vercel.app`).
5. Su iPhone, iPad o Android, apri quel link, tocca **"Condividi" -> "Aggiungi a schermata Home"**: l'app si installerà a tutto schermo come un'app nativa!

---

## 🐙 Metodo 2: GitHub Pages (Gratuito per sempre con Git)
Se usi GitHub, puoi pubblicare direttamente dal tuo repository:
1. Crea un repository su [GitHub.com](https://github.com) chiamato ad esempio `matemagica`.
2. Dal terminale o con GitHub Desktop, carica la cartella del gioco:
   ```bash
   git init
   git add .
   git commit -m "Matemagica AAA Dark Edition"
   git branch -M main
   git remote add origin https://github.com/TUO-USERNAME/matemagica.git
   git push -u origin main
   ```
3. Vai nelle **Settings** del repository su GitHub -> sezione **Pages**.
4. Sotto **Build and deployment**, seleziona il branch `main` e la cartella `/ (root)`, poi clicca **Save**.
5. In 1 minuto il tuo gioco sarà online su:
   `https://TUO-USERNAME.github.io/matemagica/`

---

## 📦 Metodo 3: Netlify Drop (Senza Terminale, Trascina la Cartella)
Se preferisci farlo dal browser senza usare la riga di comando:
1. Apri [app.netlify.com/drop](https://app.netlify.com/drop) nel browser.
2. Trascina l'intera cartella `tabelline-game` nel riquadro tratteggiato.
3. Netlify pubblicherà istantaneamente il gioco fornendoti un URL pubblico HTTPS!
